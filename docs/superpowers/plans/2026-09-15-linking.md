# Linking (0.5) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Hybrid `[[` completion, and a two-step passage picker that writes
an Obsidian-form link `[[Note#^id|words]]`, writing the anchor into the
target only when the link is made; the alias renders and hover shows the
target.

**Architecture:** One passage per note in the index, so every retrieval
stays note-level and `search::hybrid` serves search, completion and the
picker's first step alike. A pure `core::linking` module cuts a body into
blocks, picks the best one for a query, and writes an anchor. The shell adds
four commands (`link_candidates`, `blocks`, `anchor_block`, `link_preview`).
The frontend adds a `link` palette mode with two steps, an async completion
source, the `[[^^` trigger, and a hover popover.

**Tech Stack:** Rust 2024 (`rusqlite`, `regex`, `sha2`, `tempfile` for
tests), Tauri 2, Svelte 5, TypeScript, CodeMirror 6 (`@codemirror/autocomplete`),
vitest.

**Spec:** `docs/superpowers/specs/2026-09-15-linking-design.md`. The
direction spec `docs/superpowers/specs/2026-09-14-writing-first-direction-design.md`
(sections *Linking*, *Passages*, *Retrieval*) is its parent. `ROADMAP.md`
step 0.5 is the summary.

**Branch:** `feat/linking`, created from `master` at `6935bad`; the spec
commit `991b7e4` is on it. Stay on it.

## Decisions the spec leaves open

- **The "block moved" error is `Error::NotFound`**, not a new variant. The
  shell already maps `NotFound` to code `not_found`, and the UI's reaction
  (refresh the block list) keys on that code. Adding a variant would touch
  the error mapping for one message.
- **Id generation lives in the shell** with `rand`-free code: six chars from
  `[a-z0-9]` drawn from `std::time` nanoseconds mixed with a counter. Core
  only checks uniqueness. `rand` is not a dependency today and is not worth
  adding for six characters.
- **`[[^^` hands over to the palette by selecting the typed range.** The
  editor selects `[[^^query` and opens the picker with `replace = true`, so
  the existing `insertAtCursor` replaces it. No new insertion mechanism.
- **The completion popup keeps its last list while the backend answers** by
  caching the previous result in the completion source and returning it
  synchronously when the query has not changed.
- **Hover popover is one component in `NoteView`** driven by event delegation
  over both live preview (`a.cm-wikilink`) and reading mode (`a.wikilink`);
  both carry `data-target` already.

```rust
/// Truncate at the end to `MAX_CHARS`, preferring a whitespace boundary.
fn truncate(text: &str) -> &str {
    let Some((hard, _)) = text.char_indices().nth(MAX_CHARS) else {
        return text;
    };
    let at = text[..hard].rfind(char::is_whitespace).unwrap_or(hard);
    text[..at].trim_end()
}

        heading: String::new(),
        line: 1,
```

//! Link targets inside a note: blocks, the best block for a query, anchors.

use regex::Regex;
use std::sync::LazyLock;

#[derive(Debug, Clone, Copy, PartialEq, Eq, serde::Serialize)]
#[serde(rename_all = "lowercase")]
pub enum BlockKind {
    Heading,
    List,
    Paragraph,
}

/// One thing a link can point at. Lines are 1-based in the body.
#[derive(Debug, Clone, PartialEq, Eq, serde::Serialize)]
pub struct Block {
    pub kind: BlockKind,
    pub first: u32,
    pub last: u32,
    /// The lines, `^id` tokens stripped; for a heading, its text.
    pub text: String,
    pub heading: Option<String>,
}

// Obsidian's block id: `^id` ending a line, after a space or alone on it.
static BLOCK_ID: LazyLock<Regex> =
    LazyLock::new(|| Regex::new(r"(?:^|[ \t])\^([A-Za-z0-9-]+)[ \t\r]*$").unwrap());
static LIST_ITEM: LazyLock<Regex> =
    LazyLock::new(|| Regex::new(r"^([ \t]*)(?:[-*+]|\d+[.)])(?:[ \t]|$)").unwrap());

fn indent_width(s: &str) -> usize {
    s.chars().map(|c| if c == '\t' { 4 } else { 1 }).sum()
}

fn heading_text(line: &str) -> Option<String> {
    let t = line.trim_start();
    let hashes = t.len() - t.trim_start_matches('#').len();
    if hashes == 0 || hashes > 6 {
        return None;
    }
    let rest = &t[hashes..];
    rest.starts_with(' ').then(|| rest.trim().to_owned())
}

fn strip_id(line: &str) -> &str {
    match BLOCK_ID.find(line) {
        Some(m) => line[..m.start()].trim_end(),
        None => line.trim_end(),
    }
}

/// Cut a body into headings, list items with their subtrees, and paragraphs.
/// Fenced code is skipped; a line that is only `^id` belongs to the block above.
pub fn blocks(body: &str) -> Vec<Block> {
    let lines: Vec<&str> = body.lines().collect();
    let mut out = Vec::new();
    let mut i = 0;
    let mut fence: Option<u8> = None;
    while i < lines.len() {
        let line = lines[i];
        let t = line.trim_start();
        if t.starts_with("```") || t.starts_with("~~~") {
            let f = t.as_bytes()[0];
            fence = match fence {
                Some(open) if open == f => None,
                other => other.or(Some(f)),
            };
            i += 1;
            continue;
        }
        if fence.is_some() || line.trim().is_empty() {
            i += 1;
            continue;
        }
        let first = i;
        let (kind, heading) = if let Some(h) = heading_text(line) {
            i += 1;
            (BlockKind::Heading, Some(h))
        } else if let Some(m) = LIST_ITEM.captures(line) {
            let depth = indent_width(&m[1]);
            i += 1;
            // The subtree: deeper lines, and blank lines inside the run.
            while i < lines.len() {
                let l = lines[i];
                if l.trim().is_empty() {
                    let next = lines[i + 1..].iter().find(|x| !x.trim().is_empty());
                    match next {
                        Some(n) if indent_width(&n[..n.len() - n.trim_start().len()]) > depth => {
                            i += 1;
                            continue;
                        }
                        _ => break,
                    }
                }
                let ind = indent_width(&l[..l.len() - l.trim_start().len()]);
                if ind <= depth {
                    break;
                }
                i += 1;
            }
            (BlockKind::List, None)
        } else {
            i += 1;
            while i < lines.len() {
                let l = lines[i];
                let t = l.trim_start();
                if l.trim().is_empty()
                    || heading_text(l).is_some()
                    || LIST_ITEM.is_match(l)
                    || t.starts_with("```")
                    || t.starts_with("~~~")
                {
                    break;
                }
                i += 1;
            }
            (BlockKind::Paragraph, None)
        };
        let mut last = i;
        // A lone `^id` line after the block is Obsidian's paragraph anchor.
        if last < lines.len() && lines[last].trim_start().starts_with('^') && BLOCK_ID.is_match(lines[last]) {
            last += 1;
            i = last;
        }
        let text = match &heading {
            Some(h) => h.clone(),
            None => lines[first..last].iter().map(|l| strip_id(l)).collect::<Vec<_>>().join("\n").trim_end().to_owned(),
        };
        out.push(Block {
            kind,
            first: first as u32 + 1,
            last: last as u32,
            text,
            heading,
        });
    }
    out
}

```rust
/// Query terms: lowercased words of two characters or more.
fn terms(query: &str) -> Vec<String> {
    let mut t: Vec<String> = query
        .split(|c: char| !c.is_alphanumeric())
        .filter(|w| w.chars().count() >= 2)
        .map(|w| w.to_lowercase())
        .collect();
    t.sort();
    t.dedup();
    t
}

/// The block with the most distinct query terms in it; ties to the earlier.
pub fn best_block(blocks: &[Block], query: &str) -> Option<usize> {
    let terms = terms(query);
    if terms.is_empty() {
        return None;
    }
    let mut best: Option<(usize, usize)> = None;
    for (i, b) in blocks.iter().enumerate() {
        let text = b.text.to_lowercase();
        let n = terms.iter().filter(|t| text.contains(t.as_str())).count();
        if n > 0 && best.is_none_or(|(_, m)| n > m) {
            best = Some((i, n));
        }
    }
    best.map(|(i, _)| i)
}
```

```rust
use crate::{Error, Result};
use std::collections::HashSet;

#[derive(Debug, Clone, PartialEq, Eq)]
pub struct Anchored {
    pub text: String,
    pub id: String,
    pub changed: bool,
}

/// Every `^id` already in the file, for uniqueness.
pub fn existing_ids(text: &str) -> HashSet<String> {
    text.lines()
        .filter_map(|l| BLOCK_ID.captures(l).map(|c| c[1].to_owned()))
        .collect()
}

/// Append ` ^id` to the block's anchor line, or return the id it already has.
/// `body_line` is the file line the body starts on. Nothing else changes.
pub fn anchor(
    text: &str,
    body_line: u32,
    block: &Block,
    fresh: &mut dyn FnMut() -> String,
) -> Result<Anchored> {
    if block.kind == BlockKind::Heading {
        return Err(Error::NotFound("heading blocks take no anchor".into()));
    }
    // Obsidian keys a list item by its own line and a paragraph by its last.
    let body_target = match block.kind {
        BlockKind::List => block.first,
        _ => block.last,
    };
    let target = (body_target + body_line - 1) as usize - 1;
    let mut lines: Vec<&str> = text.split_inclusive('\n').collect();
    let line = *lines
        .get(target)
        .ok_or_else(|| Error::NotFound("block is outside the file".into()))?;
    let (content, eol) = match line.strip_suffix("\r\n") {
        Some(c) => (c, "\r\n"),
        None => match line.strip_suffix('\n') {
            Some(c) => (c, "\n"),
            None => (line, ""),
        },
    };
    if let Some(c) = BLOCK_ID.captures(content) {
        return Ok(Anchored {
            text: text.to_owned(),
            id: c[1].to_owned(),
            changed: false,
        });
    }
    let used = existing_ids(text);
    let mut id = fresh();
    while used.contains(&id) {
        id = fresh();
    }
    let new_line = format!("{} ^{id}{eol}", content.trim_end());
    lines[target] = &new_line;
    Ok(Anchored {
        text: lines.concat(),
        id,
        changed: true,
    })
}
```

```rust
#[derive(Debug, Clone, PartialEq, Eq, serde::Serialize)]
pub struct Preview {
    pub heading: String,
    pub text: String,
}

const PREVIEW_LINES: usize = 40;

fn heading_path(body: &str, upto_line: u32) -> String {
    let mut stack: Vec<(usize, String)> = Vec::new();
    for (i, line) in body.lines().enumerate() {
        if i as u32 + 1 >= upto_line {
            break;
        }
        if let Some(h) = heading_text(line) {
            let level = line.trim_start().len() - line.trim_start().trim_start_matches('#').len();
            stack.retain(|(l, _)| *l < level);
            stack.push((level, h));
        }
    }
    stack.into_iter().map(|(_, h)| h).collect::<Vec<_>>().join(" > ")
}

fn cap(text: String) -> String {
    text.lines().take(PREVIEW_LINES).collect::<Vec<_>>().join("\n")
}

/// The text a link points at: a block by `^id`, a heading's section, or the
/// note's first block.
pub fn preview(body: &str, fragment: Option<&str>) -> Option<Preview> {
    let all = blocks(body);
    match fragment {
        Some(f) if f.starts_with('^') => {
            let id = &f[1..];
            let line = body
                .lines()
                .position(|l| BLOCK_ID.captures(l).is_some_and(|c| c[1].eq_ignore_ascii_case(id)))?
                as u32
                + 1;
            let b = all.iter().find(|b| b.first <= line && line <= b.last)?;
            Some(Preview { heading: heading_path(body, b.first), text: cap(b.text.clone()) })
        }
        Some(f) => {
            // `[[Note#A#B]]` names heading B under A; the last part finds it.
            let want = f.rsplit('#').next().unwrap_or(f).trim();
            let i = all.iter().position(|b| {
                b.heading.as_deref().is_some_and(|h| h.eq_ignore_ascii_case(want))
            })?;
            let level = |b: &Block| {
                body.lines().nth(b.first as usize - 1).map_or(7, |l| {
                    let t = l.trim_start();
                    t.len() - t.trim_start_matches('#').len()
                })
            };
            let own = level(&all[i]);
            let end = all[i + 1..]
                .iter()
                .find(|b| b.kind == BlockKind::Heading && level(b) <= own)
                .map_or(body.lines().count() as u32, |b| b.first - 1);
            let text = body
                .lines()
                .skip(all[i].first as usize - 1)
                .take((end - all[i].first + 1) as usize)
                .map(strip_id)
                .collect::<Vec<_>>()
                .join("\n");
            Some(Preview { heading: heading_path(body, all[i].first), text: cap(text.trim_end().to_owned()) })
        }
        None => {
            let b = all.first()?;
            Some(Preview { heading: String::new(), text: cap(b.text.clone()) })
        }
    }
}
```

```rust
/// Notes whose title, stem or path contains the query, then notes `hybrid`
/// finds above the divider that spelling did not, up to `limit`.
pub fn link_candidates(
    index: &Index,
    query: &str,
    query_vec: Option<&[f32]>,
    cfg: &SearchConfig,
    mem: &MemoryConfig,
    at: i64,
    limit: usize,
) -> Result<Vec<LinkCandidate>> {
    let q = query.trim().to_lowercase();
    let mut out: Vec<LinkCandidate> = index
        .titles()?
        .into_iter()
        .filter(|(p, t)| {
            q.is_empty()
                || t.to_lowercase().contains(&q)
                || stem(p).to_lowercase().contains(&q)
                || p.to_lowercase().contains(&q)
        })
        .map(|(path, title)| LinkCandidate { path, title, kind: MatchKind::Text, primed: false })
        .collect();
    if !q.is_empty() {
        let seen: HashSet<String> = out.iter().map(|c| c.path.clone()).collect();
        let found = super::hybrid(index, query, query_vec, cfg, mem, at, limit)?;
        out.extend(
            found
                .hits
                .into_iter()
                .filter(|h| !h.past_divider && !seen.contains(&h.path))
                .map(|h| LinkCandidate { path: h.path, title: h.title, kind: MatchKind::Meaning, primed: h.primed }),
        );
    }
    out.truncate(limit);
    Ok(out)
}
```

```rust
// Six of Obsidian's characters from the clock and a counter; core rejects a
// collision, so this only has to be cheap.
fn fresh_id() -> String {
    use std::sync::atomic::{AtomicU64, Ordering};
    static N: AtomicU64 = AtomicU64::new(0);
    let t = std::time::SystemTime::now()
        .duration_since(std::time::UNIX_EPOCH)
        .map(|d| d.as_nanos() as u64)
        .unwrap_or(0);
    let mut x = t ^ N.fetch_add(0x9E37_79B9_7F4A_7C15, Ordering::Relaxed);
    const ALPHABET: &[u8] = b"abcdefghijklmnopqrstuvwxyz0123456789";
    (0..6)
        .map(|_| {
            x ^= x << 13;
            x ^= x >> 7;
            x ^= x << 17;
            ALPHABET[(x % 36) as usize] as char
        })
        .collect()
}
```

```ts
  return path.split("/").pop()!.replace(/\.md$/i, "");
}

/** The link as written: Obsidian's form, the alias after `|` when there is one. */
export function linkText(path: string, block: Block, id: string | null, alias: string | null): string {
  const fragment = block.kind === "heading" ? block.heading ?? block.text : `^${id ?? ""}`;
  const tail = alias ? `|${alias}` : "";
  return `[[${stemOf(path)}#${fragment}${tail}]]`;
}

const TRIGGER = /\[\[\^\^([^\]]*)$/;

/** Obsidian's vault-wide block search: `[[^^` and what was typed after it. */
export function blockTrigger(textBefore: string): { from: number; query: string } | null {
  const m = TRIGGER.exec(textBefore);
  return m ? { from: m.index, query: m[1] } : null;
}

/** What a block row shows: its first line, without a list marker. */
export function firstLine(block: Block): string {
  const line = block.text.split("\n")[0] ?? "";
  return line.replace(/^\s*(?:[-*+]|\d+[.)])\s+(?:\[[ xX]\]\s+)?/, "").trim();
}
```

```svelte
    const t = b.text.toLowerCase();
```

```ts
import { autocompletion, type CompletionContext, type CompletionResult } from "@codemirror/autocomplete";
import type { LinkCandidate } from "../lib/api";
import { blockTrigger } from "../lib/linkpicker";

/** Hybrid `[[` completion: the backend lists spelling matches, then meaning matches. */
export function wikiCompletion(
  candidates: (q: string) => Promise<LinkCandidate[]>,
  onBlockSearch: (from: number, to: number, query: string) => void,
) {
  return async (ctx: CompletionContext): Promise<CompletionResult | null> => {
    const before = ctx.state.sliceDoc(ctx.state.doc.lineAt(ctx.pos).from, ctx.pos);
    const trigger = blockTrigger(before);
    if (trigger) {
      const lineFrom = ctx.state.doc.lineAt(ctx.pos).from;
      onBlockSearch(lineFrom + trigger.from, ctx.pos, trigger.query);
      return null;
    }
    const m = ctx.matchBefore(/\[\[([^\]|#]*)$/);
    if (!m) return null;
    const q = m.text.slice(2);
    const found = await candidates(q);
    const options = found.map((c) => {
      const stem = c.path.split("/").pop()!.replace(/\.md$/i, "");
      return { label: c.title, detail: c.kind === "meaning" ? `meaning · ${c.path}` : c.path, apply: `[[${stem}]]` };
    });
    return { from: m.from, options, filter: false };
  };
}
```
