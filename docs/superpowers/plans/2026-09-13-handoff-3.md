## The rule that changed this session

`AGENTS.md` used to say *"KISS. One trait per seam, one implementation until a
second exists. No abstraction for a future that has not arrived."* The user
struck it: **engram-notes is meant to be a sustainable product that is better
than Obsidian, not the smallest thing that works today.** The replacement is in
`AGENTS.md` and it changes how you should judge a design — prefer the shape
that still holds at ten times the vault, and a seam a known roadmap item needs
is worth building before that work starts. It is still not licence to
speculate: an abstraction must name the real case it serves.

This matters immediately, because the next piece of work was argued down on the
old rule and the user overruled it. See *Next steps*.

## What this session built (all on `feat/obsidian-parity-ui`)

Two plans, both executed:
`docs/superpowers/plans/2026-09-13-obsidian-parity-ui-2.md` (4 tasks) and
`2026-09-13-obsidian-parity-ui-3.md` (6 tasks).

**Measured against the real Obsidian, not guessed.** Obsidian 1.13.7 is
installed as a flatpak and its `app.css` and `app.js` were extracted from
`obsidian.asar`; every number below came from there. The extraction script is
in plan 2's *Measurements* section — **use it rather than guessing, this is how
the density mistake of the previous session was avoided.**

- **The header band.** `--header-height: 40px`, `--ribbon-width: 44px`.
  Obsidian has *no* full-width tab-bar element: the band that spans the window
  is the ribbon's corner, each sidebar's own 40px header and the root split's
  tab strip, sharing one height and one background, with the ribbon pushed down
  by `margin-top`. **Nothing was lifted out of `Pane.svelte`, which is why
  split panes keep their own strips with no special case.**
- **Properties.** `propIcon(key, value)` in `ui/src/lib/properties.ts` gives
  each row Obsidian's icon: `text`, `binary` (number — not `hash`), `calendar`,
  `clock`, `check-square`, `list`, and `tags` / `forward` keyed off the *key*,
  as Obsidian's widget registry does. Heading *Properties*, shown only once the
  block holds something.
- **Explorer.** Folder chevrons (10×10, stroke 4, rotating −90° collapsed,
  24px gutter, 16px per level) and a 9px uppercase extension badge on
  non-markdown files. **Obsidian shows no icon on notes** — `.nav-file-icon` is
  dead CSS that `app.js` never creates; the user chose to match that exactly.
- **A frameless window.** `decorations: false`, our own minimise / maximise /
  close in the band, `startDragging()` for the drag (WebKitGTK ignores
  `-webkit-app-region`), `--frame-right-space: 126px` reserved under them as
  Obsidian reserves it. Confirmed working by the user.
- **Search is a Ctrl+K modal**, a third mode on `Palette.svelte` beside Ctrl+P
  and Ctrl+O, with the result list in `SearchResults.svelte`. The sidebar
  Search view and `Search.svelte` are gone, so the left sidebar holds the
  explorer alone and its actions moved into the band. The ribbon's magnifier
  opens the same modal, for discoverability.
- **The graph**: `hitRadius` (at least 10 screen pixels, whatever the zoom —
  the reason nodes could not be clicked), `fitView` (run once the simulation
  settles, capped at zoom 2), an eased zoom, and **a plain click opens the note
  in the other split** rather than over the graph.
- Obsidian's 700px `--file-line-width`, a right-aligned status bar, the ribbon
  corner's sidebar toggle, and icons on Obsidian's scale (`--icon-m` 18px,
  `--icon-s` 16px).

2. **Replace the graph's 2D canvas with a WebGL renderer.** The user asked for
   this directly and overruled the KISS objection to it. What was agreed:
   - **Not PixiJS.** Obsidian uses it, but it is ~500KB of general 2D scene
     graph for a problem with two primitives.
   - A hand-written **WebGL2** renderer: nodes as instanced circles (one draw
     call for the whole vault), edges as instanced line quads (one more),
     labels left on a 2D overlay canvas because text in WebGL needs a glyph
     atlas and is not worth it. Roughly 250 lines, no new dependency.
   - **A fallback path is required** when WebGL2 is unavailable; the existing
     `paint()` in `GraphView.svelte` becomes it. Under the new `AGENTS.md`
     rule this is a genuine second implementation, so the seam is earned.
   - Honest scope: this does **not** fix interaction or feel — those were
     separate bugs, already fixed. It buys scale. The per-frame CPU walk over
     every node and edge is what breaks down at a few thousand notes.
   - The force simulation stays on the CPU in d3, so at very large vaults the
     simulation becomes the limit, not the renderer. Say so before starting;
     if the user wants that too it is its own piece of work.

## Setting up on another machine

1. **System packages** (Fedora; adjust for your distribution):
   `webkit2gtk4.1-devel gtk3-devel libsoup3-devel librsvg2-devel
   libappindicator-gtk3-devel dbus-devel glib2-devel`. Check with
   `pkg-config --modversion glib-2.0` — 2.88.3 here. Plus a stable Rust
   toolchain and `pnpm`.
2. `git clone https://github.com/overcuriousity/engram-notes && cd engram-notes
   && git checkout feat/obsidian-parity-ui && cd ui && pnpm install`.
3. **Tests**: `cargo test --workspace` and, in `ui`, `pnpm check && pnpm test`.
   None of them need a model, a window or the network.
4. **A demo vault.** `~/engram-demo-vault` is not in the repository. Recreate
   one with folders, links, an unresolved `[[…]]`, a non-markdown file and
   enough prose on two subjects for semantic search to have something to find.
   The one used here holds `Index.md`, `Async Rust.md`, `Daily/2026-09-13.md`,
   `Kitchen/{Espresso,Grinders,Kettle descaling,Sourdough}.md` and
   `Rust/{Borrowing,Error handling,Ownership,Smart pointers}.md`.
5. **Headless screenshots** — the only check that works without a desktop:
   - `cd ui && pnpm dev` in the background, or reuse a server on 5173.
   - `node ui/scripts/shot.mjs <fixture> <out.png> [w] [h]`, with `SETTLE` (ms)
     and `EVAL` (an expression run first).
   - Fixtures live in `ui/scripts/fixtures/`; `parity2.json` and
     `parity2-dark.json` cover the band, properties, the explorer and search,
     and `ui/scripts/fixture.example.json` documents the shape. **A fixture's
     `config` must carry the `search`, `memory` and `embed` sections** or
     fields bound to them render empty.
   - Chromium comes from `~/.cache/ms-playwright/chromium-*/chrome-linux64/chrome`;
     override with `CHROME`.
6. **The real window**: `cd ui && pnpm tauri build --debug --no-bundle`, then
   `target/debug/engram-notes <vault>`. The Tauri CLI exits 0 even when it
   failed if its output is piped — **check the binary's timestamp, not the exit
   code.** The user's KDE Wayland session cannot take desktop screenshots from
   a shell, so ask them for the screenshots.
7. **Measuring Obsidian**: install it (flatpak `md.obsidian.Obsidian`) and
   extract `app.css` and `app.js` from
   `…/files/resources/obsidian.asar` with the script in plan 2's
   *Measurements* section.
8. The index is at
   `~/.local/share/engram-notes/vaults/<first 16 hex of sha256(vault path)>/index.db`.
   Reading the `vectors` blobs out of it with a short Python script is how the
   similarity floor was measured, and is the right move whenever a number needs
   choosing rather than guessing.

## Gotchas, carried forward and added

From earlier sessions and still true:

- The core library is `engram_core`; a crate named `core` breaks doctests.
- Run the Tauri CLI as `pnpm tauri <cmd>` **inside `ui`**.
- `pnpm tauri build --debug --no-bundle` embeds `ui/dist`, so a frontend change
  reaches the real window only after a rebuild.
- A Svelte component taking props must not also declare a local `let props`.
- `lucide-svelte` is deprecated; the maintained package is `@lucide/svelte`.
- An `f32` widens through JSON: 0.8 arrives as 0.800000011920929.
- `grep` on a large UTF-8 markdown file silently found nothing in this locale;
  `grep -a` worked.
- WebKitGTK paints a native `<select>` and number spinners light in either
  theme, and rings buttons after a mouse click. Headless Chromium shows
  neither.
- `pkill -f` with a pattern that appears in the same shell command kills that
  shell.

Added this session:

- **WebKitGTK ignores `-webkit-app-region`.** A frameless window drags through
  `getCurrentWindow().startDragging()`, which needs
  `core:window:allow-start-dragging` in `src-tauri/capabilities/default.json`;
  `core:default` does not include it, nor minimise, maximise, is-maximized or
  close.
- **`cancelAnimationFrame` on every input event starves an animation.** The
  eased zoom cancelled and rescheduled its frame per wheel event; a real
  gesture fires faster than 16ms, so the frame never ran and the graph looked
  frozen. It passed headlessly because a synchronous burst of six events ends,
  leaving the last frame to run. An animation loop must own itself: start one
  only when none is in flight, and let it pick up the newest target.
- Svelte 5's `bind:value` does not see `input.value = x` from a test. Use the
  native setter and dispatch `input`:
  `Object.getOwnPropertyDescriptor(HTMLInputElement.prototype, "value").set.call(el, v)`.
  And give the component a tick before typing — the palette's reset effect
  clears the query on open.
- A `position: fixed` overlay in the band must reserve its width in whatever
  sits under it, or it covers the right sidebar's icons.
