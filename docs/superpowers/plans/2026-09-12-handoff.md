Gaps inside the foundation's scope:

1. Split panes. The spec asks for horizontal and vertical splits; the plan
   left them out.
2. Clicking an image or PDF in the explorer tries to open it as a note and
   fails. The spec wants a preview where the webview can show one.
3. A corrupt index is not deleted and rebuilt. A failed watcher does not
   fall back to rescanning on window focus. In `open_vault` the watcher
   error is silently dropped.
4. Block references `[[Note#^block]]` are read as heading links.
5. Missing tests: Tauri command serialisation, editor decorations, the
   command palette.
6. The two-second open for ten thousand notes has not been measured.
7. The properties pane shows list values as raw JSON.

Deferred by the foundation plan to the graph-and-bases plan: folder rename
and delete, image embeds inside notes, inline rename in the explorer.

## User preferences learned this session

- KISS. Comments short, as `AGENTS.md` says.
- Where Obsidian inspired a feature, match Obsidian's behaviour and file
  formats. Do not reinvent.
- Visual and editing quality at least Obsidian's, whatever it costs.
- Engram is a source of concepts, not a dependency. Self-grading stays out
  of the local app.
- Air-gapped machines matter: the embedding model must be loadable from a
  directory as well as downloaded.
- The user chose inline execution of plans in the first session.

## Gotchas found the hard way

- The core library is `engram_core`. A crate named `core` shadows Rust's own
  and breaks doctests.
- Run the Tauri CLI from the repository root. `pnpm tauri <cmd>` inside `ui`
  does that. The config's `beforeDevCommand` runs inside `ui`.
- Fedora needs `webkit2gtk4.1-devel gtk3-devel libsoup3-devel
  librsvg2-devel libappindicator-gtk3-devel dbus-devel glib2-devel`. They are
  installed on the user's machine.
- markdown-it 15 ships its own types. `@types/markdown-it` conflicts with
  them; leave it out.
- TypeScript stays on 5.x; svelte-check does not accept 7.
- After adding a CodeMirror package, restart Vite with `pnpm dev --force`.
  Otherwise the stale dependency bundle loads `@codemirror/state` twice and
  the editor throws "Unrecognized extension value".
- Svelte warns when a component mutates a tab passed as a prop. `NoteView`
  reads its tab from the store by path for that reason.
- Live preview's frontmatter fold only appears when the cursor is outside
  the frontmatter; the editor starts the cursor below it.

## Checking the app without a mouse

No input automation is installed on the user's KDE Wayland session. What
worked:

1. `cd ui && pnpm dev` in the background.
2. `target/debug/engram-notes <vault>` opens that vault directly.
3. Seed `<vault>/.engram-notes/workspace.json` with
   `{"tabs":["A.md","B.md"],"active":1}` to open notes, and set
   `editor.default_mode` in `app.json` to see another mode.
4. `spectacle -b -n -f -o shot.png`, then read the image.
5. Stop processes with a bracketed pattern such as
   `pkill -f "[t]arget/debug/engram-notes"`. An unbracketed pattern matches
   the shell running `pkill` and kills it.
